## 🛠️ 推薦工具

| 工具 | 用途 | 連結 |

| Runway Gen-3 | 高品質動畫生成 | https://runwayml.com |
| Pika Labs | 簡單上手的圖生視頻 | https://pika.art |
| MiniMax 海螺 | 免費額度多 | https://hailuoai.com |
| Midjourney | 靜態角色圖生成 | https://midjourney.com |

## 🚀 快速開始

1. 準備你家貓咪的清晰正面照
2. 選擇下方 Prompt 模板，替換 `[貓咪描述]` 為你的貓咪特徵
3. 上傳照片 + Prompt 到 Kling AI「圖生視頻」功能
4. 用 CapCut / 剪映 剪輯三段影片，加上音效
